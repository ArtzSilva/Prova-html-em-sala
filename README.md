# Conheça João Pessoa

Site de HTML puro sobre a cidade de João Pessoa (PB), feito como avaliação da disciplina de HTML. O projeto usa apenas HTML semântico, sem CSS e sem JavaScript.

**Autor:** Arthur Oliveira Silva
**Professor:** Israel da Costa Cunha
**Ano:** 2026

## Páginas

| Arquivo | Conteúdo |
|---|---|
| `index.html` | Apresentação da cidade, curiosidade e perguntas rápidas |
| `html/pontos.html` | Tabela de praias, avaliação e fotos |
| `html/cultura.html` | Perguntas frequentes, áudio local, citação e data da prova |
| `html/sugestoes.html` | Formulário de sugestões |

## Requisitos atendidos

- 4 páginas com menu de navegação em todas
- Estrutura semântica: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Tabela 3x3 com `rowspan` (`pontos.html`)
- Formulário com `date`, `range`, `file`, `datalist`, `required` e `placeholder`
- `details` e `summary` em `index.html` e `cultura.html`
- `figure` e `figcaption` em `index.html` e `pontos.html`
- Marcações avançadas: `abbr`, `mark`, `del`, `ins`, `blockquote`, `cite`, `progress` e `meter`
- Áudio local na pasta `audio/`
- `time` com a data da prova e comentário HTML sobre uma dificuldade
- Nenhum uso de CSS (`style`, `<style>`, `<center>`, `cellpadding`, `align`)

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.
3. Use o menu para navegar entre as páginas.
